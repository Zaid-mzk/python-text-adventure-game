# Python Text Adventure Game

A beginner-friendly text-based adventure game built using Python.

## Features

* Interactive story gameplay
* Multiple choices and outcomes
* Win/Lose conditions
* Beginner Python concepts

## Concepts Used

* Variables
* input()
* if / elif / else
* Nested conditions
* String methods

## How to Run

```bash
python game.py
```
